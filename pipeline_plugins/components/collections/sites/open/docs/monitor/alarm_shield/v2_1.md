# 监控平台(Monitor) - 蓝鲸监控告警屏蔽(按范围) 2.1

在 2.0 的业务、IP、节点屏蔽及时间配置基础上，增加「屏蔽结束处理方式」。

| 参数值 | 页面选项 | 行为 |
| --- | --- | --- |
| `notify_once` | 屏蔽结束后发送一次通知（默认） | 期间拦截通知和处理；结束后，对仍未恢复的告警各补发一次通知 |
| `close` | 屏蔽结束时不再通知 | 期间产生的告警不通知、不执行处理套餐；结束时关闭，不补发、不补执行 |

「结束」包含到期和提前解除。`close` 不影响屏蔽开始前已有的告警，后续新产生的告警按原策略处理。
结束处理方式在创建屏蔽后不可修改；如需改变，请新建屏蔽。

输入字段为 `bk_alarm_shield_end_policy`，可引用变量，缺省或空值使用 `notify_once`；
其他值会使节点失败，不创建屏蔽。输出仍为 `shield_id` 和 `message`。

使用条件：目标监控 `add_shield` 接口须支持顶层 `end_policy`。SOPS 多租户版通过
`bk-monitor` 网关客户端（`packages/bkapi/bk_monitor`）调用 `add_shield`，请求体整体透传；
需确保目标部署及网关侧接受并透传该字段。若旧接口忽略该参数，`close` 的行为无法保证，
应先完成目标接口升级和验收。

旧模板仍使用原插件版本和原有请求；只有显式选择 2.1 的节点提供新选项。
解除屏蔽节点沿用创建时的处理方式，无需另填参数。
