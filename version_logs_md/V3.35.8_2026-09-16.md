# V3.35.8 版本更新说明

### 新增

- [ 新增 ] 标准运维接入 IAM V4，支持多租户权限模型、资源查询和权限申请
- [ 新增 ] 支持 IAM V4 系统模型、资源操作及角色的校验和注册

### 优化

- [ 优化 ] 统一项目、流程、任务、轻应用、周期任务和定时任务等资源的权限校验
- [ 优化 ] 完善前端无权限提示及 IAM V4 权限申请链接生成
- [ 优化 ] 更新 IAM V4 网关客户端及多租户用户认证处理

### 修复

- [ 修复 ] 修复流程模板操作记录异常问题

### 升级注意事项

- IAM 客户端依赖由 `bk-iam==2.0.3` 调整为 `bk-resource==0.4.11`，`blueapps` 更新至 `4.16.rc6`
- 默认模块执行数据库迁移时会同步 IAM V4 系统模型和角色；部署前需确认目标环境的 IAM V4 网关可访问，且应用身份和租户配置正确
- 部署前建议执行 `python manage.py check_iam_v4_model` 校验本地模型，并回归多租户权限申请、资源查询及项目/流程/任务操作
