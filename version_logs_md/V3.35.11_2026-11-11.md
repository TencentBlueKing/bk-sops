# V3.35.11 版本更新说明

### 新增

#### AI

- [ 新增 ] 接入 AI 小鲸，可查标准运维的使用说明，并按当前页面补充提示。通过网关 MCP 调用时，返回内容会去掉多余字段。
- [ 新增 ] 模板可以配置任务失败分析和执行总结，通过通知发到指定群。
- [ 新增 ] 提供流程、任务、周期任务、执行记录分析等MCP

#### 权限与多租户

- [ 新增 ] 标准运维接入权限中心新版本（IAM V4）。项目、流程、任务、轻应用、周期任务和定时任务按新模型校验权限。没有权限时，页面给出申请入口。
- [ 新增 ] 支持多租户。远程插件请求会带上租户，插件列表同时包含全租户插件和当前租户插件。未开启多租户时，仍按单租户运行。
- [ 新增 ] 个人中心可按企业空间加载能看到的项目。周期任务、计划任务按用户时区展示。

#### 插件

- [ 新增 ] 流程编排可以直接使用第三方插件。所有插件都可以使用全局密码变量，第三方插件里的密码输入会自动解密。
- [ 新增 ] 新增节点管理插件，设置 `BK_NODEMGR_ENABLE=1` 后才会出现，并支持多租户调用。可以同时隐藏旧的 Nodeman 插件。
- [ 新增 ] 企微通知支持 markdown_v2。监控「解除屏蔽」可以一次解除多个策略。作业平台部分插件可以用 host_id 作为服务器参数。插件执行带上调用链信息，便于对照上下游日志。

#### 任务与流程

- [ 新增 ] 新建任务时可以带上一次执行填过的参数。
- [ 新增 ] 可以给节点自动重试设置间隔上限。
- [ 新增 ] 周期任务列表可以筛出所用流程已有更新的任务。
- [ 新增 ] 流程可以嵌入其他系统的页面（iframe），地址和顶栏按嵌入场景调整。
- [ 新增 ] 任务、流程、项目的操作会留下审计记录，并记下委托操作人和代理执行人。

#### 任务卡住后的检查和处理

- [ 新增 ] 可以定时检查页面上还在执行、后台已经没有对应进程的任务，生成案例，查看详情，导出排查材料，并执行恢复动作。处理页面只有平台超管能看到。相关开关默认全部关闭，需要按运维手册逐项打开。
- [ 新增 ] 回调失败会按级别重试，过期回调不再反复打扰。补偿扫描默认关闭。需要启用时，同时设置 `BKAPP_PLUGIN_GATEWAY_ENABLE=1` 和 `BKAPP_ENABLE_PLUGIN_GATEWAY_SWEEP=1`，并重启 Beat 进程。

#### 网关接口

- [ 新增 ] 新增或补齐这些接口：任务有效执行时长、模板备注、按时间和创建方式过滤任务列表、HTTP 回调批量更新、用 YAML 创建模板时复用已有子流程、创建任务时传入执行方案、查询计划任务、修改执行代理人和执行通知、返回职能化任务认领地址、查询节点最近一次执行记录。
- [ 新增 ] 查询节点最近执行记录时，会校验项目和租户范围。流程详情可以按需返回 webhook 配置。webhook 配置接口可以单独开关。

### 优化

#### 使用体验

- [ 优化 ] 没有权限时，提示里带上新版权限中心的申请链接。流程权限的审批人改为创建人和最后修改人。两人都已离职时，需要联系助手单独处理。
- [ 优化 ] 公共流程的可见范围支持批量搜索，并可以复制、粘贴。参数引用太长时，输入框后面的内容仍然能看到。
- [ 优化 ] 插件目录按来源提前加载。节点执行记录改为按需查询，不再一次加载全部记录。

#### 查询、清理与表达式

- [ 优化 ] 网关任务列表的翻页、关键词和「最近一次执行」查询做了收窄。未执行任务列表和未执行节点的详情同样收窄，并保留租户隔离。
- [ 优化 ] 任务清理可以按项目单独配置清理范围。清理历史任务时，会一并删除遗漏的引擎日志。
- [ 优化 ] 表达式（Mako）默认在独立子进程里计算，并检查允许使用的模块。未配置环境变量时，`BKAPP_MAKO_RENDER_BACKEND=subprocess`、`BKAPP_MAKO_RENDER_NO_NETWORK=0`、`BKAPP_MAKO_RENDER_OS_HARDEN=1`、`BKAPP_MAKO_RENDER_FALLBACK_INPROCESS=0`。存量流程要用到的模块需要按环境下发，然后重启对应进程。显式设置 `BKAPP_MAKO_RENDER_NO_NETWORK=1` 时，容器需要支持网络隔离。

### 修复

#### 流程执行

- [ 修复 ] 修复独立子流程回调互相覆盖导致任务停住的问题，并提供恢复工具。
- [ 修复 ] 修复已配置自动跳过的节点在运行时无法再手动跳过，子流程逐个更新和批量更新结果不一致，以及编辑周期任务并更换模板后，新建的周期任务缺少新节点。
- [ 修复 ] 修复带循环的流程导出 YAML 时卡住，尚未执行的子流程节点变量显示失败，以及部分内置插件失败后 HTTP 回调没有发出。

#### 变量、插件与参数

- [ 修复 ] 修复新建任务复用上次参数时文本下拉框填不回去，下拉框变量结构和提示不对，输入 $ 联想变量时找错，以及数字变量的输入提示不对。
- [ 修复 ] 修复切换插件版本后仍然兼容的参数被清掉，第三方插件的密码变量不再生效，以及解密后的内容被写进日志。
- [ 修复 ] 修复 IPv6 参数取值不对，周期表达式的时间说明翻译不对，以及快速执行脚本使用密码变量报错。
- [ 修复 ] 修复公共流程无法保存，流程名因空格编码不同而搜不到，不允许修改的常量被改掉，以及变量隐藏条件只有最后一条生效。

#### 权限、接口与页面

- [ 修复 ] 修复变量预览、流程预览、导入前检查、周期任务列表等接口未校验权限的问题。
- [ 修复 ] HTTP 请求插件不再访问解析到内网地址的目标，可用 `ENABLE_HTTP_PLUGIN_DOMAINS_CHECK` 控制。远程插件从 Git 拉取包时的代码执行风险已堵住。自动化测试辅助接口默认关闭（`BKAPP_AUTO_TEST_ENABLE`）。节点回调密钥可用 `BKAPP_CALLBACK_KEY` 替换内置值。
- [ 修复 ] 修复网关日志接口未确认节点和 trace 是否属于当前任务，`get_task_node_log`、`get_task_plugin_log` 的权限和参数，以及 `create_template` 按业务 ID 调用失败。
- [ 修复 ] 修复多租户下用户列表为空、用户名显示不对，嵌入其他系统时页面地址和顶栏不同步，前端打包后流程列表空白，创建任务按钮可以连点，条件分支删掉默认条件后旧数据还在，流程模板操作记录异常，以及资源回调接口的参数校验。
