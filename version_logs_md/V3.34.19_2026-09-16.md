# V3.34.19 版本更新说明

### 新增

- [ 新增 ] 支持通过网关查询节点最近执行记录，流程详情接口支持按需返回 webhook 配置
- [ 新增 ] 补齐任务、流程和项目等操作审计，支持记录委托操作人与代理执行人

### 优化

- [ 优化 ] 优化未执行任务列表查询及未执行节点详情加载性能
- [ 优化 ] 完善插件网关的业务范围识别、JOB 回调和目录异常隔离
- [ 优化 ] 完善回调重试的日志分级与过期回调降噪
- [ 优化 ] 完善卡住诊断的补充扫描窗口、误判排除和控制台展示
- [ 优化 ] 完善流程表单下拉参数、变量编辑和节点配置交互

### 修复

- [ 修复 ] 修复子流程常量丢失及 YAML 导入时渲染标记处理问题

### 升级注意事项

- 引擎依赖仍为 `bamboo-pipeline==4.0.5`，对应 `bamboo-engine==3.0.6`
- 保留上一版本的 Mako 安全配置及默认子进程渲染行为；存量流程的导入模块和兼容配置仍需按部署环境下发
- 本版本包含上一版本号更新后同步的业务变更，部署前需回归审计、任务查询、插件回调和诊断扫描等受影响功能
