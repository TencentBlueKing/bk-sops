# V3.35.3 版本更新说明

### 新增

- [ 新增 ] 多租户适配收尾：租户初始化参数、报错文案统一、远程插件透传 `X-Bk-Tenant-Id`、全租户与单租户插件列表合并
- [ 新增 ] 单租户→多租户数据迁移与运维工具（全量/增量同步、校验、备份恢复、任务挂起与状态检查等）
- [ 新增 ] AI 分析通知：模板可配置 AI 通知类型与群聊，支持任务失败分析与执行总结（默认关闭，需显式开启）
- [ 新增 ] 智能体流程编排与 MCP 相关网关能力（受环境变量与项目开关控制）
- [ 新增 ] 插件统一接入 OpenTelemetry span（`BasePluginService` / `plugin_execute` / `plugin_schedule`）
- [ 新增 ] 周期任务与计划任务时区处理完善
- [ 新增 ] 任务「等待处理」状态 favicon 与顶部状态样式

### 优化

- [ 优化 ] 网关任务有效执行时间等接口逻辑下沉与整理
- [ 优化 ] 监控告警屏蔽（按策略）插件支持返回全量策略数据
- [ 优化 ] HTTP 插件域名校验与 webhook 重试相关配置可配置化

### 修复

- [ 修复 ] 恢复网关 `get_task_node_log` / `get_task_plugin_log` 路由的 `task_id` 与 `project_id` 参数，并同步网关资源定义
- [ 修复 ] AI 通知配置读取移至开关判断之后，避免一次性任务或模板缺失时影响 webhook 事件广播
- [ 修复 ] 个人中心企业空间加载、时区获取机制等体验问题
