# V3.35.7 版本更新说明

### 新增

- [ 新增 ] 支持通过网关查询节点最近执行记录，并校验项目与租户范围
- [ 新增 ] 补齐任务、流程和项目等操作审计，支持记录委托操作人与代理执行人

### 优化

- [ 优化 ] 优化未执行任务列表及节点详情查询，保留租户隔离条件
- [ 优化 ] 完善插件网关 JOB 回调的租户上下文传递与客户端恢复
- [ 优化 ] 完善回调重试分级、卡住诊断补充扫描和控制台展示
- [ 优化 ] 完善流程表单交互、子流程常量和 YAML 渲染标记处理
- [ 优化 ] 插件网关超时补偿扫描默认关闭，停用时同步禁用已有周期调度记录
- [ 优化 ] 智能体入口与任务分析统一使用包含环境路径的服务地址

### 修复

- [ 修复 ] 网关初始化失败时立即中止部署，避免后续步骤掩盖同步错误

### 升级注意事项

- 引擎依赖仍为 `bamboo-pipeline==4.0.5`，对应 `bamboo-engine==3.0.6`；保留上一版本的 Mako 安全配置及默认子进程渲染行为
- 需要启用插件网关超时补偿扫描时，同时设置 `BKAPP_PLUGIN_GATEWAY_ENABLE=1` 和 `BKAPP_ENABLE_PLUGIN_GATEWAY_SWEEP=1`，并重启相关 Beat 进程
- `AI_SOPS_AGENT_URL` 需包含目标环境路径，例如 `https://agent.example.com/prod`；不再依赖旧的 `BK_SOPS_AGENT_HOST` 拼接地址
- 已有网关日志资源需按 [日志接口迁移说明](../docs/zh_hans/deploy/apigw_log_resource_migration.md) 核对和迁移；初始化失败会中止部署，需处理原因后重试
- 部署前需回归租户隔离、JOB 回调、智能体入口和日志接口调用
