# V3.35.8 版本更新说明

### 优化

- [ 优化 ] Web / API / 回调进程默认使用 2 个 gunicorn worker，并错开回收窗口
- [ 优化 ] 调整多模块进程默认规格与副本，并补充实例扩缩容说明
- [ 优化 ] 无 ESB 公钥时继续完成发布，并移除多租户旧 ESB 初始化逻辑
- [ 优化 ] 未配置智能体地址时关闭相关 AI 入口和通知

### 修复

- [ 修复 ] 多租户任务节点详情初始化时折叠按钮未展示

### 升级注意事项

- 发布后核对 `default` / `api` / `callback` 的 `GUNICORN_WORKER_NUM=2`、`GUNICORN_MAX_REQUESTS=2000`；PaaS 里已有环境变量会覆盖描述文件默认值
- 默认不再部署 `v1-engine`；仍有 V1 引擎存量任务时需自行加回该进程
- 进程规格、副本和 gunicorn 调整见 [PaaS 进程规格与实例运维](../docs/zh_hans/deploy/paas_process_scale.md)
