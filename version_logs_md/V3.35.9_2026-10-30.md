# V3.35.9 版本更新说明

### 新增

- [ 新增 ] 支持 KMS 密钥管理，在 Web、后台任务进程和管理命令启动时解密敏感配置
- [ 新增 ] 支持同步智能体初始化包，包含智能体、技能及 MCP 工具绑定配置，并接入部署流程
- [ 新增 ] 部署时自动初始化 `system` 租户的 ITSM 审批流程

### 优化

- [ 优化 ] 完善 IAM V4 全资源扫描和子资源鉴权处理
- [ 优化 ] 多租户主机选择及主机 Agent 状态查询适配节点管理接口
- [ 优化 ] 智能体默认只绑定指定的只读工具，示例知识库不参与自动同步

### 修复

- [ 修复 ] 修复 IAM V4 资源回调参数校验、网关接口鉴权及 JOB 权限申请链接问题
- [ 修复 ] 修复周期任务和计划任务提交按钮在无权限时的悬停抖动
- [ 修复 ] 兼容配置平台接口的错误码和错误信息字段，正确返回失败原因及权限申请提示
- [ 修复 ] 修复加密字段在 Python 3.11 下复制失败导致数据库迁移报错的问题

### 升级注意事项

- `blueapps[opentelemetry,bkcrypto,kms]` 更新至 `4.16rc7`；启用 KMS 时需设置 `BKPAAS_KMS_ENABLED=true`，并确认平台已挂载所需密文配置
- 智能体自动同步默认关闭；`BKAI_SYNC_ENABLED` 仅在 `1/true/yes/on` 时开启，忽略大小写和首尾空格。启用前需核对 `BKAI_TENANT_ID`、`BKAI_SPACE_ID` 和访问凭据；可通过 `BKAI_PACKAGE` 指定初始化包
- 智能体同步会写入并发布目标空间配置，失败会中止部署；默认包不导入示例知识库，也不修改已有知识库绑定
- 延续 V3.35.8 的 IAM V4 模型和角色注册流程，部署前需确认 IAM V4 网关、应用身份和租户配置正确；部署后需验证权限申请、KMS 解密及已启用的智能体同步
