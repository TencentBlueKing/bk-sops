# V3.35.4 版本更新说明

### 新增

- [ 新增 ] 插件网关：统一内置与第三方插件目录，支持插件执行调度、回调收敛与 uniform api v4 网关接口（默认关闭，需通过 BKAPP_PLUGIN_GATEWAY_ENABLE 显式开启；多租户环境需关注来源配置的租户语义）
- [ 新增 ] 插件网关支持透传插件原生表单协议，并增加表单访问与身份校验
- [ 新增 ] 卡住流程治理：接入流程诊断能力，支持诊断周期扫描、运行中但无存活进程的任务检测、病历列表与详情、诊断动作与告警、证据导出（相关开关默认全部关闭，需按运维手册显式开启）
- [ 新增 ] 新增卡住流程治理控制台，支持查看病历、管理状态与执行诊断恢复动作，仅平台超管可见
- [ 新增 ] 新增节点管理（nodemgr）插件，通过 BK_NODEMGR_ENABLE=1 控制可见性
- [ 新增 ] 支持流程画布 AI 自动排版，并提供功能开关
- [ 新增 ] 支持以 iframe 方式嵌入其他系统，路由与页头按嵌入场景自适应
- [ 新增 ] 所有插件支持全局密码变量，第三方插件密码输入支持自动解密
- [ 新增 ] 新建任务支持复用上一次执行的参数
- [ 新增 ] 周期任务支持筛选查看存在更新的流程
- [ 新增 ] 支持配置节点自动重试间隔上限
- [ 新增 ] 个人中心支持按企业空间加载项目范围
- [ 新增 ] 网关 create_template 接口支持 YAML 格式复用已有子流程模板
- [ 新增 ] 网关创建任务接口支持执行方案参数，get_template_schemes 接口支持 with_constants 返回变量详情
- [ 新增 ] 网关新增计划任务查询、流程模板执行代理人修改、流程模板执行通知修改、业务级项目执行代理人修改接口
- [ 新增 ] 职能化任务列表接口支持筛选，创建任务接口返回职能化任务认领地址，并新增认领任务网关配置
- [ 新增 ] webhook 配置接口支持控制开关，支持修改 HTTP 请求开关配置

### 优化

- [ 优化 ] 优化 APIGW 任务列表分页查询、任务列表关键词筛选与最新执行任务查询的执行计划
- [ 优化 ] 优化节点执行记录查询，避免全量加载
- [ 优化 ] 按插件来源提前加载插件目录，提升目录访问性能
- [ 优化 ] 优化常用项目权限查询，并补充默认项目切换的权限校验
