# 业务归属维度流程特征

> 基于全量 **46,107 条流程、1,207 个业务**，按业务归属维度提炼的流程差异与 Review 要点。
>
> 自研、发行、平台、海外四种业务归属在运维成熟度、工具链集成深度、合规要求上存在显著差异，直接影响流程设计模式。

---

## 分类总览

| 类别 | 流程数 | 业务数 | 平均节点 | 中位节点 | 并行率 | 排他率 | 核心特征 |
|------|--------|--------|---------|---------|--------|--------|----------|
| [自研业务](01_自研业务.md) | 15,524 | 125 | 7.2 | 3 | 13.5% | 11.6% | 工具链集成最深、TCM 重度依赖、定制化插件丰富 |
| [发行业务](02_发行业务.md) | 6,189 | 43 | 7.3 | 3 | 13.3% | 9.9% | GCS 工单驱动、合服/开区高频、GCloud 深度使用 |
| [平台与工具](03_平台与工具.md) | 4,355 | 88 | 4.9 | 3 | 8.3% | 24.7% | 排他网关最高、HTTP API 驱动、审批流程完善 |
| [海外业务](04_海外业务.md) | 199 | 6 | 1.9 | 1 | 2.0% | 8.5% | 流程最简、轻量级工具链、以脚本执行为主 |

> 注：约 19,840 条流程（946 个业务）因业务名称无法明确归类而未纳入上述分类。

---

## 业务归属如何影响流程设计

### 1. 工具链集成深度
- **自研业务**：拥有最深的内部工具链集成。TCM（12,629 次）、BKChat（877+844 次）、蓝盾流水线（533 次）深度融入流程
- **发行业务**：依赖 GCS 工单系统（787 次 gcs_bill_execute + 520 次 gcs_sqlserver）和 GCloud（472 次 gcloud_pre_publish），体现开发商协作模式
- **平台与工具**：以 HTTP API 调用为核心（3,945 次 bk_http_request，远超其他类别），体现平台化、API 化特征
- **海外业务**：工具链最轻量，主要依赖基础脚本执行（job_fast_execute_script）

### 2. 运维成熟度梯度
```
自研业务 > 发行业务 > 平台工具 > 海外业务
（完善的告警/通知/审批闭环） （标准化但依赖外部协作） （自动化程度高但场景单一） （基础脚本为主）
```

### 3. 关键差异对比

| 维度 | 自研 | 发行 | 平台 | 海外 |
|------|------|------|------|------|
| 核心组件 | job_fast_execute_script + TCM | job_execute_task + GCS | bk_http_request | job_fast_execute_script |
| DB 操作 | BKChat 审批集成 | DBM + GCS SQL 工单 | 较少 | 极少 |
| 发布模式 | 灰度 → 预发布 → 正式 | GCloud 预发布 → 发布 | BCS/Helm 部署 | 直接发布 |
| 告警管理 | TNM2 + 蓝鲸监控双重屏蔽 | TNM2 为主 | 蓝鲸监控为主 | 较少使用 |
| 审批机制 | BKChat 机器人 + ITSM | 人工确认为主 | 蓝鲸审批 + ITSM | 基础暂停确认 |
| 通知渠道 | 企业微信 + BKChat + 邮件 | 企业微信 + BKChat | BKChat 为主 | 基础通知 |
| 合服/开区 | 部分涉及 | 高频（299 次合服） | 不涉及 | 不涉及 |

### 4. Review 侧重点

| 业务归属 | 重点检查 |
|---------|----------|
| 自研 | TCM 配置变更原子性、灰度策略完整性、告警屏蔽闭环 |
| 发行 | GCS 工单状态检查、GCloud 发布一致性、开发商操作边界 |
| 平台 | API 调用容错、审批流程合规性、跨业务操作权限 |
| 海外 | 多地域网络延迟考虑、合规要求、基础监控覆盖 |
