# 定时周期

> 周期性执行的运维任务。包括定时备份、定时巡检、定时重启、自动化报告等。
>
> **215** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 必须设置定时器控制执行时间（当前采用率 13%）
2. 定时任务执行完成后发送通知（当前采用率 20%）
3. 定时任务执行后需验证结果（当前采用率 1%）
---
## 代表性流程图

**流程 1**（17 个节点）:
```
开始 → 变量预处理（新增统一文件位置） → 获取业务字段 → 判断需要执行的分支 → [并行] → 扁鹊服务可用性检查 → 00-自动化测试，输出异常结果 → dsc自动探测 → 控制台数据获取 → [汇聚] → 获取各个服务成功率数据 → 集群zone-gaas pod状态数据 → 分发控制台报告文件 → 结果数据上报（重构掉，只传入console和bianque的基础信息，结构化录入文件） → 获取各个服务延迟数据 → BkChat通知插件 → 集群deployment状态数据 → 结束 → 集群pod状态数据 → 集群版本状态数据 → 检查域名指向 → 结束
```

## 通用模式

### 常见标准子流程

**1. 定时任务标准序列**
```
定时器触发 → 执行任务脚本 → 结果校验 → 通知
```

**2. 周期巡检序列**
```
定时器触发 → [并行] → 巡检项A | 巡检项B → [汇聚] → 结果汇总 → 通知
```
