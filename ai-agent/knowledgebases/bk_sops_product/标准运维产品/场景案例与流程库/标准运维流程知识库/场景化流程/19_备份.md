## 通用模式

### 常见标准子流程

**1. 标准备份序列**
```
备份（全量/增量） → MD5校验 → 定时等待（传输完成） → 通知结果
```

**2. 多库并行备份**
```
[并行] → 备份库A | 备份库B | 备份库C → [汇聚] → 校验完整性 → 通知
```

**3. 备份+清理序列**
```
备份当前数据 → 压缩归档 → 清理过期备份 → 通知
```
