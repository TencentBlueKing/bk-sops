# 体验服测试服

> 体验服和测试服的日常管理。包括版本更新、环境搭建、CBT 环境维护、提审环境准备等。
>
> **2651** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 测试服操作前必须有人工确认（当前采用率 12%）
2. 部署后必须执行功能验证（当前采用率 4%）
3. 测试服更新完成后发送通知（当前采用率 25%）
---

## 通用模式

### 常见标准子流程

**1. 测试服更新序列**
```
停止进程 → 版本更新 → 启动进程 → 通知 → 人工确认
```

**2. 体验服发布序列**
```
人工确认（版本确认） → 停止进程 → 版本更新 → 启动进程 → 通知验证 → 人工确认
```

**3. 多测试服并行更新**
```
[并行] → 测试服A更新 | 测试服B更新 → [汇聚] → 通知 → 验证
```
