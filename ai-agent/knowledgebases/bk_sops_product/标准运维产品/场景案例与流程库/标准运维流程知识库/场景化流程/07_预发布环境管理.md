## 通用模式

### 常见标准子流程

**1. 预发布环境部署序列**
```
文件分发 → MD5校验 → 备份当前版本 → 部署新版本 → 人工确认 → 通知
```

**2. 预发布验证序列**
```
部署到预发布环境 → TCM配置同步 → 启动进程 → 健康检查 → 人工确认
```

**3. 预发布到正式的同步流程**
```
预发布验证通过 → 配置同步到正式 → TCM检查配置 → 人工确认
```
