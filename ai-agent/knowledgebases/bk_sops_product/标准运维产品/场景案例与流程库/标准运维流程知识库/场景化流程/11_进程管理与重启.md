# 进程管理

> 游戏各类服务进程的启停、重启。常见模式包括"一半一半重启"、"分批次重启"、"stop+start"等。
>
> **984** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 重启前必须摘除 CLB 流量，重启后恢复（当前采用率 1%）
2. 重启期间必须屏蔽告警，完成后取消（当前采用率 13%）
3. 停进程 → 清共享内存 → 启进程 三步完整（当前采用率 3%）
4. 进程启动后必须执行健康检查（当前采用率 7%）
5. 关键重启操作前必须有人工确认（当前采用率 22%）
6. 分批重启时每批之间必须有确认节点（当前采用率 14%）
7. 更新文件分发完成后再重启进程（当前采用率 8%）
8. 重启开始和完成时发送通知（当前采用率 13%）

## 通用模式

### 常见标准子流程

**1. 无损滚动重启序列（CLB模式）**
```
CLB摘A组流量 → 停止A组进程 → 清共享内存 → 启动A组进程 → 健康检查 → CLB恢复A组权重 → 人工确认 → CLB摘B组流量 → 停止B组进程 → 清共享内存 → 启动B组进程 → 健康检查 → CLB恢复B组权重
```

**2. 停服重启标准序列**
```
告警屏蔽 → 停止进程 → 清共享内存 → 更新配置 → 启动进程 → 健康检查 → 取消告警屏蔽 → 通知
```

**3. 分批重启序列**
```
人工确认 → 重启前半部分进程 → 人工确认（验证） → 重启后半部分进程 → 人工确认（验证） → 通知
```

**4. 配置推送+重启序列**
```
文件分发（新配置/版本） → 停止进程 → 清共享内存 → 刷bus → 启动进程 → 健康检查
```

**5. 多实例并行重启**
```
[并行] → 重启实例1 | 重启实例2 | 重启实例3 → [汇聚] → 健康检查 → 通知
```
