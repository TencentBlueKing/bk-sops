# 合服开新服

> 服务器合并与新区开放流程。复杂度较高（平均 11.8 节点），涉及数据库合并、区服导航更新、新区部署、清档等。
>
> **2102** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 合服必须先停服 → 清共享内存 → 执行合服操作（当前采用率 1%）
2. 合服关键步骤前必须有人工确认（当前采用率 21%）
3. 合服前必须执行全量数据备份（当前采用率 6%）
4. 合服期间必须屏蔽告警（当前采用率 6%）
5. 开新服后必须同步 CMDB 信息（当前采用率 17%）
6. 合服前关闭外网登录 → 操作 → 恢复（当前采用率 1%）
7. 合服/开服开始和完成时发送通知（当前采用率 10%）

---

## 通用模式

### 常见标准子流程

**1. 合服标准序列**
```
人工确认 → 告警屏蔽 → 停服 → 清共享内存 → 关闭外网登录 → 执行合服工具 → 人工确认（检查结果） → 更新版本包 → 刷bus → 启动进程 → 人工确认（验证） → 恢复外网登录 → 取消告警屏蔽 → 通知
```

**2. 开新服初始化序列**
```
申请服务器 → 人工确认 → 初始化 → 配置DNS → 安装组件 → 初始化数据盘 → 安装agent → 配置网络 → 人工确认
```

**3. 开区DB序列**
```
生成区服SQL → 人工确认 → 配置区服数据库 → 人工确认 → CMDB同步信息
```

**4. 开区配置序列**
```
TCM配置外发 → TCM检查配置 → 检查TCM新增进程 → 人工确认 → 下发配置 → 刷新bus → 启动进程 → 通知
```
