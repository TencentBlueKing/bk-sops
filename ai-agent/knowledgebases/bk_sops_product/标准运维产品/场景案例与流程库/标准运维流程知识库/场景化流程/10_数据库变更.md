# 数据库变更

> 涵盖 MySQL、Redis、MongoDB 等数据库的结构变更、数据更新、SQL 执行等。
>
> **366** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 数据库变更前必须执行备份（当前采用率 3%）
2. SQL 执行前必须有人工确认（当前采用率 5%）
3. 数据库变更必须经过审批（当前采用率 14%）
4. 变更后必须执行数据校验（当前采用率 0%）
5. 变更开始时发送通知（当前采用率 6%）

---

## 通用模式

### 常见标准子流程

**1. DB 变更标准序列**
```
备份 → 审批 → 人工确认（SQL确认） → 执行SQL → 验证数据 → 通知
```

**2. 并行多库提单序列**
```
[并行] → gamedb提单 | accountdb提单 | logdb提单 → [汇聚] → 人工确认
```

**3. DBM 标准变更序列**
```
DBM提交SQL → DBM确认 → DBM执行 → DBM轮询状态 → 通知结果
```

## 检查清单

| 检查项 | 说明 | 严重程度 |
|--------|------|--------|
| 🔴 变更前备份 | 变更前是否有数据库备份 | 高 |
| 🔴 审批确认 | 高危 SQL 是否有审批确认（pause_node/bk_approve） | 高 |
| 🟡 回滚脚本 | 是否准备回滚 SQL | 中 |
| 🟡 维护窗口 | 变更是否在维护窗口内执行 | 中 |
| 🟡 变更后验证 | 变更后是否有数据验证 | 中 |
| 🟡 权限控制 | SQL 执行是否有权限控制 | 中 |
