## 关键检查点

1. 必须包含标准审批节点（当前采用率 50%）
2. 审批发起时发送通知（当前采用率 2%）
3. 审批完成后发送通知（当前采用率 27%）

## 通用模式

### 常见标准子流程

**1. ITSM 审批标准序列**
```
提交ITSM工单 → 审批 → 人工确认（确认审批结果） → 执行操作 → 通知
```

**2. 多级审批序列**
```
审批（一级） → 人工确认 → 审批（二级） → 审批（最终） → 执行操作
```
