## 通用模式

### 常见标准子流程

**1. AI 分析序列**
```
数据采集 → AI模型分析 → 结果格式化(Markdown) → 通知/邮件
```

**2. AI + 人工确认序列**
```
AI分析 → 通知结果 → 人工确认（确认AI建议） → 执行操作 → 通知
```
