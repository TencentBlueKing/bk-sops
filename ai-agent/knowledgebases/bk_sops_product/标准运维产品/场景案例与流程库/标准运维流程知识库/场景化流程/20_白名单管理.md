# 白名单

> 服务器/账号白名单的增删管理。用于灰度测试、内部体验、安全访问控制等。
>
> **319** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 白名单变更前必须有人工确认（当前采用率 6%）
2. 白名单变更需经过审批（当前采用率 9%）
3. 白名单变更完成后发送通知（当前采用率 14%）
---
## 代表性流程图

**流程 1**（17 个节点）:
```
开始 → 企业微信收到加白需求 → 确认clb归属账号以及VIP的地域等信息 → [条件] → 输入账号，输入个人密码 → 【可xxx快速登录】 → 打开小程序，找到MFA → 找对应的安全组ID → 输入6位验证码 → 【如果是指定范围段，不用审批默认过单】 → [汇聚] → 如果是第一次开，要再登录下xxx云去绑定下 → 企业微信收到加白需求 → 企业微信收到加白需求 → 企业微信收到加白需求 → 企业微信收到加白需求 → 企业微信收到加白需求 → 企业微信收到加白需求 → 企业微信收到加白需求 → 企业微信收到加白需求 → 结束
```

**流程 2**（16 个节点）:
```
开始 → 开发群通知 → 新增白名单上传 → 追加玩家白名单 → 发布群通知 → 分发玩家白名单 → 开启账号白名单功能 → 检查白名单状态 → 检查运维机白名单 → 检查服务器白名单 → 白名单弹框提示无资格 → 确认白名单弹框状态 → 蓝鲸审批 → 重载玩家白名单 → 获取重载结果 → 发布群通知 → 开发群通知 → 结束
```

**流程 3**（7 个节点）:
```
开始 → 运维审批 → [条件] → [汇聚] → 重启TCM → [并行] → [汇聚] → checkconf → createcfg *.1.4.* → 运维审批 → pushcfg *.1.4.* → 刷新完成通知 → 结束
```

**流程 4**（7 个节点）:
```
开始 → 白名单文件添加 → 暂停 → 生成配置文件+push → 暂停 → 灰度重启进程 → 暂停 → 重启所有进程 → 结束
```

**流程 5**（6 个节点）:
```
开始 → 快速执行脚本 → [并行] → [汇聚] → 蓝鲸审批 → PowerApp功能插件-RPC版 → 执行作业 → bkchat通用消息通知 → BkChat通知插件 → 结束
```

**流程 6**（5 个节点）:
```
开始 → 生成UUID → 下载-校验-压缩 → itsm审核群机器人通知 → 白名单文件分发gateway → 检查tcm是否在使用中 → 结束
```

**流程 7**（5 个节点）:
```
开始 → Job-本地文本框内容上传 → 备份文件 → 生成新白名单文件 → 替换tpl文件并重启 → 发送通知 → 结束
```

**流程 8**（5 个节点）:
```
开始 → 操作时间 → Job-分发本地文件 → 追加新的白名单 → 暂停 → Job-全服Reload进程 → 结束
```

## 通用模式

### 常见标准子流程

**1. 白名单变更序列**
```
审批 → 人工确认 → 更新白名单 → 验证生效 → 通知
```

**2. 批量白名单管理**
```
审批 → [并行] → 更新区服A白名单 | 更新区服B白名单 → [汇聚] → 通知
```
