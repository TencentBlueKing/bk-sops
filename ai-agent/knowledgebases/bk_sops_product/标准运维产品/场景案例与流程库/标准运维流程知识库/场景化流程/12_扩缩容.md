# 扩缩容

> 根据业务负载动态调整服务器资源。包括 CVM 升降配、一键扩容/缩容、机器上下架等。
>
> **1135** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 扩缩容后必须同步 CMDB 主机信息（当前采用率 10%）
2. 扩容后必须注册 CLB，缩容前必须摘除 CLB（当前采用率 5%）
3. 扩缩容期间必须屏蔽告警（当前采用率 3%）
4. 关键扩缩容步骤前必须有人工确认（当前采用率 13%）
5. 新机器/服务启动后必须执行健康检查（当前采用率 2%）
6. 缩容前必须执行数据备份（当前采用率 2%）
7. 扩容后必须同步 TCM 配置（当前采用率 2%）
8. 扩缩容开始和完成时发送通知（当前采用率 3%）

## 通用模式

### 常见标准子流程

**1. 机器上架标准序列**
```
SA初始化 → 空闲检查 → 配置DNS → 转移主机模块(CMDB) → 告警屏蔽 → 数据盘格式化 → 安装组件 → 配置网络 → 内核升级 → 人工确认
```

**2. RS 上线标准流程**
```
CLB查询 → 添加RS → 设置初始权重 → 逐步提升权重 → 验证
```

**3. 扩容后配置同步序列**
```
CMDB同步主机信息 → TCM配置下发 → 启动进程 → 健康检查 → CLB注册新机 → 通知
```

**4. 缩容下架标准序列**
```
CLB摘流量 → 停止进程 → 数据备份/迁移 → CMDB转移到空闲模块 → 取消告警屏蔽 → 通知
```

**5. CVM 升降配流程**
```
人工确认 → 停止进程 → CVM变更配置 → 等待变更完成 → 启动进程 → 健康检查 → 通知
```
