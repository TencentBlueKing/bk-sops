## 通用模式

### 常见标准子流程

**1. 告警屏蔽管理序列**
```
告警屏蔽（TNM2 + 蓝鲸监控） → 人工确认（变更完成） → 取消告警屏蔽（TNM2 + 蓝鲸监控）
```

**2. 自动巡检序列**
```
[并行] → 巡检项A | 巡检项B | 巡检项C → [汇聚] → 结果汇总 → 通知
```

**3. 告警处理序列**
```
告警触发 → 告警屏蔽 → 处理操作 → 验证恢复 → 取消告警屏蔽 → 通知
```
