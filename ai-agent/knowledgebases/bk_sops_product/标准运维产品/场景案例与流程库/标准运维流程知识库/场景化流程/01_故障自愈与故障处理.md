# 故障自愈

> 自动化故障检测与恢复。包括进程自愈、磁盘清理、时间同步、机器替换、主机转移故障模块等。覆盖面最广，几乎所有业务都部署了故障自愈套餐。
>
> **7993** 条流程 | 平均节点数基于采样分析

---

## 关键检查点

1. 自愈操作前后必须有告警屏蔽/取消屏蔽闭环（当前采用率 0%）
2. 故障处理开始时发送通知（当前采用率 2%）
3. 故障处理完成后发送通知（当前采用率 41%）
4. 故障恢复后必须执行健康检查（当前采用率 0%）
5. 关键恢复操作前必须有人工确认（当前采用率 1%）

## 通用模式

### 常见标准子流程

**1. 故障机替换流程**
```
通知 → 审批 → CMDB转移故障机 → CMDB转移备机 → 初始化新机 → CLB摘故障机流量 → CLB注册新机 → CLB恢复权重 → 通知
```

**2. 进程自愈重启流程**
```
告警触发 → 通知 → 重启进程 → 重启进程（多实例） → 健康检查 → 通知结果
```

**3. 磁盘清理自愈流程**
```
告警触发 → 日志清理脚本 → 磁盘使用率检查 → 通知结果
```

**4. 故障机下架流程**
```
CLB摘流量 → 停止进程 → CMDB转移到故障机模块 → 通知运维
```

**5. 服务恢复验证流程**
```
启动进程 → 健康检查 → 通知 → 启动进程（下一批） → 健康检查 → 通知
```
