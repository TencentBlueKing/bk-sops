> 音舞类以 QQ 炫舞系列为代表，以音乐节奏和社交互动为核心。运维流程特点是配置/CDN 更新频繁、DBM SQL 变更深度集成、蓝鲸通知密度全子类最高、TNM2 告警屏蔽/解除管理规范。

## 关键检查点（Review 要点）

1. **配置更新+CDN 联动**：配置（15.0%）+CDN（3.9%）合计 18.9%，需确认配置更新后的 CDN 缓存刷新
2. **DB SQL 变更审批链**：DBM 三件套 61 次，需确认 SQL 执行→确认→轮询的完整审批链路
3. **TNM2 屏蔽/解除完美配对**：43:41 ≈ 1:1，是最佳实践标杆。但仍需检查少数未配对的场景
4. **BSCP 配置发布**：bscp-onebtn-pub 用于配置快速发布，需确认配置版本管理和灰度策略
5. **服务端文件分发一致性**：server_file_dispatch（154 次）频繁使用，需确认多机器间的文件一致性
6. **AI SRE 巡检结果处理**：ai-tgsre-bkm（11 次），需确认巡检异常的告警和处理流程

```
SRE-稳定性巡检 → sa服务器类型检查 → SRE-CC主机计费模式切换 → SRE-检查云石FTP → 消息展示×4
```

