## 关键检查点（Review 要点）

1. **Helm + GCloud 双轨一致性**：gn-helm 用于 BCS 部署，GCloud 用于客户端发布，需确认两个渠道的版本一致性
2. **安全补丁覆盖**：部分业务有安全补丁流程（分发→检查OS→安装→验证），需确认所有机器的补丁覆盖
3. **安全组巡检**：弹性网卡安全组检查流程（巡检→AI 总结→判断是否告警→邮件），需确认巡检覆盖率
4. **条件并行分支完整性**：条件并行 14.2% 最高，需检查各条件分支的处理完整性
5. **机器升降配安全性**：升降配流程（检查→暂停→关机→CVM升降配→挂载→检查）需确认告警屏蔽和恢复
6. **节点管理 Agent 安装**：nodeman_create_task（14 次），需确认 Agent 安装后的健康检查
7. **Mac 构建机管理**：mac-reboot 反映特殊的构建环境，需确认重启后的服务恢复

## 代表性流程

**流程 1**：机器升降配（13 节点）
```
降配前检查 → 暂停-确认开始 → 蓝鲸监控告警屏蔽 → tmp告警屏蔽 → CVM升降配-关机立即执行 → 定时4min → gse_agent检查 → 关机后去掉注释fstab → 重新挂载 → 降配后检查 → tmp告警解除 → 蓝鲸告警解除
```
> 特点：完整的升降配流程 — 双重告警屏蔽 + CVM 操作 + 挂载恢复 + 检查

**流程 2**：GCloud 发布 puffer/dolphin（5 节点）
```
获取发布差异 → GCloud发布确认审核-安卓 → GCloud发布确认审核-iOS → [条件并行] puffer-publish-安卓 + dolphin-publish-iOS
```
> 特点：GCloud 双渠道条件并行发布

**流程 3**：安全补丁安装（8 节点）
```
检查操作系统是否2019 → 人工确认 → 分发文件到software → 检查分发 → software下安装补丁 → 检查安装 → 脚本检查补丁 → 通知
```
> 特点：安全运维的标准流程 — 前置检查 + 分发 + 安装 + 多重验证
