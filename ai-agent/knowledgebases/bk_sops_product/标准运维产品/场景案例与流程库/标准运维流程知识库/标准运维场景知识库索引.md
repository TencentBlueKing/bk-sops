# 标准运维场景知识库索引

> 基于 **46,107 条生产流程、1,207 个业务**提炼的运维知识库。
>
> 知识库按三个互补维度组织，帮助从不同角度理解和优化流程编排。

## 三维度概览

| 维度 | 目录 | 回答的问题 | 文件数 |
|------|------|-----------|--------|
| 场景 | `scene/` | 用户要**做什么**（发布、重启、扩缩容…） | 26 |
| 游戏类型 | `genre/` | 业务**是什么类型的游戏**（FPS、MOBA、MMO…） | 14 + README |
| 业务归属 | `ownership/` | 业务**属于什么组织类型**（自研、发行、平台、海外） | 4 + README |

## 加载规则

| 规则 | 说明 |
|------|------|
| 始终加载 | `00_通用组件与最佳实践模式.md`（全局通用，不属于任何维度） |
| 场景匹配 | 根据用户操作意图，从 `scene/` 加载 1–2 个最相关的场景文件 |
| 游戏类型匹配 | 若已知业务的游戏类型，先加载 `genre/00_总览.md` 识别类型，再加载对应详情文件 |
| 业务归属匹配 | 若已知业务归属，先加载 `ownership/00_总览.md` 识别归属，再加载对应详情文件 |
| 上限 | 单次加载不超过 4 个文件（00 + 场景 1-2 个 + 游戏类型/业务归属各 0-1 个） |
