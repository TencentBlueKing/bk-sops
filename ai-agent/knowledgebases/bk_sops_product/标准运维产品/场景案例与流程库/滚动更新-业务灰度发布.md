# 四、配置方法

## 1.全局变量

| **名称** | **key** | **默认值** | **含义** |
| - | - | - | - |
| iplist | ${iplist} | IP选择器 | 执行的目标IP |
| 循环计数 | ${_loop_count} |  | 循环执行的次数 |
| IP个数 | ${count} | ${len(iplist.split(','))} | 使用Python语法计数IP个数,[参考](https://github.com/Tencent/bk-sops/blob/V3.6.X/docs/features/variables_engine.md) |
