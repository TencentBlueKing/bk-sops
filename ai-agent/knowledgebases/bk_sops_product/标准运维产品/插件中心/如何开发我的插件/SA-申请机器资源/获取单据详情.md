请求url: http://cfm-portal.bkapps-sz.oa.com/api/sa/get_machine_by_bill_id/

  

字段说明：

| **字段** | **字段类型** | **是否是可选参数** | **说明（参数值）** |
| - | - | - | - |
| bill_id | string | 否 | 申请单据id |
| username | string | 否 | 单据申请人 |


参考示例：

```json
{
	"bill_id": "1007832",
	"username": "lucifersu"
}
```

返回示例：


机器全部到位：（result为True，data有数据）

```json
{
	"result": true,
	"code": 0,
	"message": "",
	"data": {
		"D4-4-200-10": "9.66.152.7,11.192.186.208,9.66.152.156,11.192.172.40,9.67.182.228",
		"V-NCP": "11.192.132.20",
		"D2-4-50-10": "9.79.242.109",
		"D4-20-100-10": "11.192.185.204"
	}
}
```

单据尚未匹配完成（result为True，data无数据）

```json
{
	"result": true,
	"code": 0,
	"message": "",
	"data": {}
}
```


单据异常：（result为False，data无数据，message输出对应信息）

```json
{
	"result": false,
	"code": 0,
	"message": "单据bill_id:100044，已被终止，请联系SA资源管理员查看",
	"data": {}
}
```
