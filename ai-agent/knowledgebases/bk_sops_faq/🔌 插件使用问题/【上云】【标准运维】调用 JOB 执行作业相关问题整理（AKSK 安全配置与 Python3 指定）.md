# 标准运维调用 JOB 执行作业相关问题整理

## 一、问题背景

本次沟通围绕标准运维中调用 JOB 执行作业的两个问题展开：

1. **从标准运维调用 JOB 执行脚本时，需要传入腾讯云 AKSK 密钥，如何配置更符合安全规范**
2. **JOB 执行时，如何指定 Python 3 版本执行**

## 二、沟通过程整理

### 1. AKSK 密钥传入的安全配置

用户首先咨询：

> 从标准运维调用 JOB 执行脚本，需要传入腾讯云 AKSK 密钥，要怎么配置才符合安全规范？

在沟通过程中，相关同学确认了标准运维中所使用的插件类型。最初先确认是否为：

- **作业平台（JOB）-快速执行脚本**

随后用户补充说明，实际使用的是：

- **作业平台（JOB）-执行作业**

针对该插件，确认结果是：

- **该插件支持使用“密码类型”的变量**
- 可优先评估是否能满足对 AKSK 等敏感信息安全传递的需求


### 2. JOB 中指定 Python 3 版本执行

后续用户继续咨询：

> JOB 执行的时候，怎么指定 Python3 版本执行？

沟通中给出的建议是：

- 可以在脚本开头**显式指定目标机器上的 Python 3 路径**
- 例如使用 shebang 或明确调用对应解释器

参考示例如下：

```python
#!/usr/bin/pythonxx
# 请替换为目标机器上的实际 Python 3 路径
print("当前 Python 版本:", __import__('sys').version)
```
