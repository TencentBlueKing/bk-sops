## 问题
需求场景：调用外部的接口来确认任务是否执行完
标准运维插件开发中，如果调用一个外部接口，可能需要耗时3分钟左右才能有分析结果，这个有什么处理方案吗？在主机上直接调用无耗时问题

## 解决方案
context.storage["task_id"] = xxx 在State.EMPTY 状态下，产生一个task_id, 然后在State.POLL 判断这个task_id 状态进行处理后续的流程
```
state = get_task_state(context.storage["task_id"])
        if state == "SUCCESS":
            return  # 任务执行成功，本次调用成功
        elif state == "FAIL":
            raise self.Error("task fail")  # 任务执行失败，本次调用失败
        elif state == "RUNNING":
            self.wait_poll(5)  # 五秒后再次执行
```
如果外部接口本身是阻塞的，那得在插件框架管理自己的celery任务
