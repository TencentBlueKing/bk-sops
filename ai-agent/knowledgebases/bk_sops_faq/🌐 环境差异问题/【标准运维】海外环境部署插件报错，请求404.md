## 问题描述：

将国内环境的标准运维插件代码直接拿到海外环境（sg.crosgame.com）部署时报错，修改 `app_desc.yml` 中的 `BK_APIGW_MANAGER_URL_TMPL` 为海外地址后部署成功，但请求仍然 404。

## 解决方法：

问题原因是 `app_desc.yml` 中的 `BK_APIGW_MANAGER_URL_TMPL` 默认配置的是国内地址，需要改为海外地址，且注意 URL 末尾斜杠格式。

**修改方式：**

将 `app_desc.yml` 中的配置：

```yaml
- name: BK_APIGW_MANAGER_URL_TMPL
  value: http://{api_name}.apigw.woa.com
```

改为海外地址（注意末尾不要多余斜杠）：

```yaml
- name: BK_APIGW_MANAGER_URL_TMPL
  value: http://bkapi.sg.crosgame.com/api/{api_name}/
```

> 注意：`{api_name}` 后面需要保留一个斜杠，参考正确格式配置。
