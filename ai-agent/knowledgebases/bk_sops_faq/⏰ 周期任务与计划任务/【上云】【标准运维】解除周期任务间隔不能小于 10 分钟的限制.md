## 问题描述

解除周期任务间隔不能小于 10 分钟的限制。

## 解决方法

在联系标准运维开发团队申请解除限制前，需要准备以下信息：

| 确认项 | 说明 |
| - | - |
|  业务名称 / bk_biz_id  |  说明是哪个业务的需求  |
|  需要的执行间隔  |  具体需要多少分钟执行一次（如 1 分钟、5 分钟）  |
|  周期任务数量  |  计划创建几个高频周期任务  |
|  业务场景说明  |  为什么需要高频执行，用途是什么（调度负载评估用）  |
|  预计运行时长  |  单次任务执行大概需要多久完成  |

> ⚠️ **特别注意：** 之所以有此限制，是因为历史上有业务创建了大量高频无用定时任务，导致任务调度负载过高影响其他业务。因此申请时需要说明合理性。
