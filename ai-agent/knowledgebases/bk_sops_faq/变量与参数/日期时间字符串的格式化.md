# 日期时间字符串的格式化

> 公开基础说明。本文已重新编写，不沿用原始案例或截图转写。示例不代表任何实际部署配置。

下面演示 Python 日期时间格式化，不涉及产品页面设置：

```python
from datetime import datetime

sample_time = datetime(2000, 1, 1, 8, 30)
date_text = sample_time.strftime("%Y-%m-%d")
datetime_text = sample_time.strftime("%Y-%m-%d %H:%M:%S")
assert date_text == "2000-01-01"
assert datetime_text == "2000-01-01 08:30:00"
```

日期字符串不等同于带时间的字符串；没有时区信息的值也不能自动代表某个确定时区。
