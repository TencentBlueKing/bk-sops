# 字符串相等与包含的区别

> 公开基础说明。本文已重新编写，不沿用原始案例或截图转写。示例不代表任何实际部署配置。

以下是独立的 Python 语言示例，不代表某个产品的网关表达式配置。

```python
assert "alpha" != "alpha_worker"
assert "alpha" in "alpha_worker"
assert "alpha" not in ["alpha_worker", "beta"]
assert "alpha" in ["alpha", "beta"]
```

`==` 比较值是否相等；字符串中的 `in` 判断子串，列表中的 `in` 判断元素。需要完全匹配时，不应把子串判断当作相等判断。
