## 问题描述：

我想在标准运维模板里面获取对应业务的 BKCC 里面的内网 IP 列表，有什么变量可以直接获取呢？

## 解决方法：

标准运维没有一个直接返回「业务全部内网 IP」的内置变量，但提供了两种全局变量类型可以实现需求，根据场景选择：

**✅ 方案一：IP 选择器（推荐）**

全局变量类型选择 **IP选择器**，支持两种模式：

| 模式 | 说明 |  
| 静态 IP | 手动选择/输入业务下的主机，固定后不变 |  
| 动态 IP | 选择 CMDB 拓扑树节点（集群/模块），每次执行时实时拉取该节点下的当前主机列表 |

引用方式：

```
${KEY}
```

返回格式为英文逗号分隔的内网 IP 字符串，例如：

```
10.0.0.1,10.0.0.2,10.0.0.3
```

如果需要带云区域信息，可在变量配置中开启「变量值是否带云区域」：

```
0:10.0.0.1,0:10.0.0.2
```

💡 如果想获取业务下所有 IP：使用动态 IP 模式，在拓扑树中选择业务根节点，即可每次执行时自动拉取整个业务的主机列表。

**✅ 方案二：集群模块 IP 选择器**

全局变量类型选择 **集群模块IP选择器**，适合按集群/模块维度筛选 IP 的场景：

- 支持选择指定集群和服务模板，自动获取其下的 IP
- 支持手动输入集群模块名称
- 支持筛选集群名称、服务模板名称

引用方式：

```
${KEY}  // 返回逗号分隔的 IP 字符串
```

**📝 使用步骤**

1. 打开流程模板编辑页，进入 **全局变量** 面板
2. 点击 **新建变量**
3. 变量类型选择 **IP选择器** 或 **集群模块IP选择器**
4. 配置模式（推荐动态 IP）：动态 IP → 在拓扑树中选择业务根节点或指定集群/模块
5. 在后续插件节点（如作业平台插件）的「目标服务器」参数中引用 `${KEY}` 即可

**⚠️ 注意事项**

- 动态 IP 每次执行时实时从 CMDB 获取，能反映主机的最新状态，推荐用于生产场景
- 静态 IP 添加后不随 CMDB 变化，适合固定目标机器的场景
- 输入不合法的 IP（非当前业务下的 IP）会被自动过滤掉
- 如果通过 API 创建任务传 IP，IP选择器变量直接在 `constants` 中传字符串值即可（逗号分隔）
