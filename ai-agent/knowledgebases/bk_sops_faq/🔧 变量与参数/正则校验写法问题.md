# 正则表达式的完整匹配

> 公开基础说明。本文已重新编写，不沿用原始案例或截图转写。示例不代表任何实际部署配置。

以下是独立的 Python 校验示例，文件名完全虚构：

```python
import re

pattern = r"sample_[a-z0-9]+\.txt"
assert re.fullmatch(pattern, "sample_alpha.txt") is not None
assert re.fullmatch(pattern, "prefix_sample_alpha.txt") is None
assert re.fullmatch(pattern, "sample_alpha.txt.backup") is None
```

需要校验整个字符串时可使用 `fullmatch`。其他语言或产品表单的正则实现可能不同，不能直接假设所有语法兼容。
