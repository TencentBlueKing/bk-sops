# 条件表达式的基础概念

> 公开基础说明。本文已重新编写，不沿用原始案例或截图转写。示例不代表任何实际部署配置。

以下仅说明 Python 的比较和逻辑运算：

```python
sample_count = 4
assert sample_count > 0
assert sample_count > 0 and sample_count < 10
assert not (sample_count == 0)
```

`and`、`or`、`not` 分别表示逻辑与、或、非。组合多个条件时可以用括号明确含义。

产品中的表达式引擎未必支持完整 Python；本页不声明任何运行模块白名单或执行权限。
